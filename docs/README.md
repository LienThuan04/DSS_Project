# Documentation — DSS Customer Churn Project

This folder contains all project documentation, reports, diagrams, and assets for the Decision Support System (DSS) for Telecom Customer Churn Prediction.

## Folder Structure

### `/screenshots`
UI screenshots and visual assets for the report and demo documentation.

**Contents:**
- Customer list with Predict button
- Prediction result modal
- Dashboard charts (risk distribution, churn by segments)
- What-if simulation before/after comparison
- Explainability panel showing top factors

### `/diagrams`
System architecture and data flow diagrams.

**Contents:**
- `architecture.png` — System architecture (React, NestJS, ML API, MongoDB)
- `data-flow.png` — Data flow between components
- Editable sources (`.drawio` files for Draw.io)

### `/assets`
Supporting resources: images, derived datasets, reference materials.

**Contents:**
- Dataset descriptions
- EDA outputs
- Model evaluation charts
- Other supporting materials
