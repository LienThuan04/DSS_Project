# Customer Churn Decision Support System (DSS)

**Full Task Specification (A → Z)**
Tech Stack: **Python (ML) + ReactJS + NestJS + MongoDB**

---

# 1. Project Overview

## 1.1 Project Title

**Decision Support System for Customer Churn Prediction**

## 1.2 Objective

Develop a **web-based Decision Support System (DSS)** that analyzes telecom customer data and predicts whether a customer is likely to leave the service (churn).

The system helps managers:

* Analyze customer behavior
* Predict churn probability
* Identify high-risk customers
* Make retention decisions

---

# 2. Dataset Information

Dataset provided by instructor:

```
WA_Fn-UseC_-Telco-Customer-Churn.csv
```

Notebook provided:

```
telco_customer_churn.ipynb
```

### Dataset Description

The dataset contains telecom customer information and whether they churned.

Target variable:

```
Churn (Yes / No)
```

Example fields:

| Column          | Description                          |
| --------------- | ------------------------------------ |
| customerID      | Customer unique ID                   |
| gender          | Male / Female                        |
| SeniorCitizen   | 0 or 1                               |
| Partner         | Yes / No                             |
| Dependents      | Yes / No                             |
| tenure          | Months with company                  |
| PhoneService    | Yes / No                             |
| InternetService | DSL / Fiber / No                     |
| Contract        | Month-to-month / One year / Two year |
| PaymentMethod   | Payment method                       |
| MonthlyCharges  | Monthly fee                          |
| TotalCharges    | Total spending                       |
| Churn           | Target label                         |
